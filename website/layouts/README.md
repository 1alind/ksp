# 📐 AURA Layouts & Global Components

This directory contains global reusable template components, headers, footers, and translation helpers.

---

## 📁 File Structure

| File | Description |
| :--- | :--- |
| **`header.php`** | **Global Navigation & Topbar**. Announcement bar, brand logo, navigation links, quick search drawer, cart counter badge, language dropdown (EN, AR, KU), and theme switcher (Dark/Light). |
| **`footer.php`** | **Global Footer & Guarantees**. Guarantee badges (Authenticity, Fast Delivery, Secure Payment), category links, accepted payment methods, and copyright. |
| **`translations.php`** | **Localization Core**. Helper functions (`t($key, $lang)`) for translating labels into English, Arabic, and Kurdish Badini. |
